# 🖤 Wednesday – Student Web Project

🌐 **Live Demo:**  
https://dusharaekanayaka0314-coder.github.io/wednesday-student-web-project/

A small beginner-friendly web project created as part of my **Web Development** learning journey.

I built this project to practise the basic concepts I was learning in HTML, CSS and JavaScript and to understand how different frontend elements work together to create an interactive webpage.

---

## 📌 About the Project

This project is a themed website inspired by the **Wednesday** series.

The main goal was not to build a large or complex application, but to create a small project where I could learn and practise frontend development concepts through a practical example.

While building it, I focused on understanding:

- How an HTML page is structured
- How CSS is used to design and style a webpage
- How JavaScript can make a webpage interactive
- How different sections of a webpage are organized
- How images and other assets are used in a website
- How to make a webpage responsive
- How to publish a project using GitHub Pages

---

## ✨ Features

- 🎬 Wednesday-themed landing page
- 🧭 Navigation between different sections
- 👥 Interactive cast section
- 🎞️ Cast carousel with next/previous controls
- 🖱️ Mouse hover and interactive effects
- 🌧️ Animated background effects
- ⚡ Lightning effect
- 📱 Responsive layout
- 🎮 Simple JavaScript-based "Nevermore Mystery" game
- 🌐 Live website hosted with GitHub Pages

---

## 🛠️ Technologies Used

- **HTML5** – Page structure and content
- **CSS3** – Styling, layout, animations and responsive design
- **JavaScript** – Interactions, carousel, effects and the mini game
- **GitHub Pages** – Website hosting

---

## 📚 What I Learned

This project helped me understand the connection between the three main frontend technologies:

### HTML
I practised creating the structure of a webpage using elements such as:

- Headings
- Paragraphs
- Links
- Images
- Buttons
- Sections
- Navigation
- Footer

### CSS
I practised:

- Layout and positioning
- Colours and typography
- Spacing
- Responsive design
- Hover effects
- Animations
- Styling cards and sections

### JavaScript
I used JavaScript to add interaction to the webpage, including:

- Interactive buttons
- Cast carousel controls
- Mouse interactions
- Keyboard interactions
- Dynamic effects
- A small guessing game

---

## 🎯 Purpose of the Project

The purpose of this project was to learn by building something small and practical.

Instead of only studying HTML, CSS and JavaScript separately, I wanted to see how they work together in an actual webpage.

This project is especially useful as a beginner practice project because it helped me move from learning individual concepts to using them together.
